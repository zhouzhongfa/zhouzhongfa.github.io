欢迎使用“Word文档办公”（以下简称“本应用”）。我们重视您的隐私，并遵循最小必要原则处理信息。本政策说明本应用在提供文档管理、文字识别、PDF 处理和格式转换功能时如何处理数据。

本应用无需注册或登录，不接入广告，不进行跨应用跟踪，也不出售您的个人信息。

一、我们处理的信息

1. 本地文件和生成内容

您主动导入、创建或生成的文档保存在本应用的沙盒文档目录中。除非您主动使用在线格式转换功能，否则我们不会将这些文件上传至服务器。您可以通过本应用或系统“文件”App管理和删除这些文件。

2. 本地文字识别和 PDF 处理

图片文字识别使用 Apple Vision 在设备端完成；PDF 合并、拆分、压缩、加密、PDF 与图片互转等功能在设备端完成。相关图片、文字和 PDF 内容不会因这些本地功能上传至我们的服务器。

3. 在线格式转换

当您主动选择文件并点击“开始转换”时，为完成 PDF、Word、PPT 或表格格式转换，所选文件、原始文件名、目标格式和完成转换所必需的技术信息会通过加密连接发送至我们的转换接口，并转交给专业文件转换服务提供商处理。

  • 处理目的：仅用于执行您主动发起的格式转换并返回结果。
  • 处理范围：仅处理您在该次操作中明确选择的文件。
  • 保存期限：我们的应用服务器仅建立临时文件并在上传完成后立即删除；转换服务提供商会按照其数据保留规则自动清理任务文件和结果。
  • 处理地点：转换服务提供商的服务器可能位于中国大陆以外地区。若您不希望文件通过网络或在境外处理，请勿使用在线格式转换功能；本地 OCR 和 PDF 工具仍可继续使用。

4. 基础网络信息

您访问在线转换接口时，网络基础设施可能为保障安全与稳定而产生短期服务器日志，例如请求时间、IP 地址、响应状态和异常信息。我们不会使用这些信息建立用户画像或投放广告。

二、设备权限

权限使用场景是否必需
相机拍摄、扫描纸质文档仅在使用扫描功能时需要
照片选择图片进行文字识别或生成 PDF仅在使用相关功能时需要
文件访问由您通过系统文件选择器导入、打开或保存文档仅访问您主动选择的文件

您可以随时前往 iOS“设置”修改相机或照片权限。拒绝某项权限只会影响对应功能。

三、第三方处理服务

本应用未集成广告或用户分析 SDK。在线格式转换由我们的 Java 后端与 CloudConvert 文件转换服务共同完成。该服务仅在您主动发起在线转换时接收所选文件。

  • 服务提供方：CloudConvert GmbH
  • 用途：文档格式转换和转换结果的临时交付
  • 可能处理的信息：所选文件、文件名、目标格式及必要的网络技术信息
  • 服务方隐私说明：https://cloudconvert.com/privacy

四、信息安全

在线请求使用 HTTPS 加密传输；转换服务密钥只保存在后端，不会打包进本应用。我们采取合理的访问控制和临时文件清理措施，但任何网络传输或电子存储方式均无法保证绝对安全。请避免上传包含高度敏感个人信息、商业秘密或依法不得跨境传输的文件。

五、儿童隐私

本应用不是专门面向儿童设计的服务，也不会要求用户提交年龄、姓名或联系方式。如果监护人发现未成年人通过在线转换功能提交了不适当的信息，可通过本政策末尾的方式联系我们。

六、您的权利

您可以在本应用或系统“文件”App中查看、导出或删除本地文件。卸载本应用通常会删除其沙盒内的数据。对于在线转换任务的相关疑问，您可以联系我们提出访问、更正、删除或解释请求，我们将在核实后依法处理。

七、政策更新

当功能、数据处理方式或法律要求发生变化时，我们可能更新本政策，并在本页面修改更新日期。发生重大变化时，我们会通过应用内适当方式进行提示。
